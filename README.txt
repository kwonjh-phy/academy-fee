우리 아이 학원비 관리 PWA

설치 및 배포
1. 압축파일을 풀고 내부 파일 5개(index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png)를 GitHub Pages가 서비스하는 저장소의 폴더에 업로드하세요. icon.svg는 선택 사항입니다.
2. HTTPS 주소로 접속하세요. (file:// 로 직접 열면 PWA 설치/오프라인 기능이 작동하지 않습니다.)
3. 갤럭시 Chrome에서 메뉴(⋮) → '홈 화면에 추가' 또는 '앱 설치'를 누르세요.
4. 앱에서 학원을 등록하고 월별 납부 체크를 하세요. 데이터는 해당 브라우저의 localStorage에 저장됩니다.
5. '백업 파일 저장'을 주기적으로 사용하세요. 다른 기기에서는 백업 복원으로 이전할 수 있습니다.

주의: 브라우저 저장 데이터 삭제, 비공개 모드, 기기 초기화 시 기록이 사라질 수 있습니다. 여러 기기 간 자동 동기화는 지원하지 않습니다. 납부일 29~31일은 해당 날짜가 없는 달에 자동 알림을 제공하지 않습니다. 알림 기능은 미포함입니다.
